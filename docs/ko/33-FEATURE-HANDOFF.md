# 기능 개발 핸드오프

## 쿼리 의존성 자동 추출 정확도 검증

독립 H2 주문 fixture에서 마이그레이션 버전·파일 체크섬과 관측된 변경을 연결했다. 이력이 없는 동일 변경과 무관하게 관측된 변경은 미해결로 남겼다. [마이그레이션과 스키마 영향](27-SCHEMA-IMPACT-REGRESSION.md)

## 범위와 인수 조건

검증된 주문 쿼리·컬럼 매니페스트를 기준으로 사용한다. fixture의 정적 쿼리부터 테이블·컬럼 추출 결과를 명시적 참조와 대조한다. 동적 SQL과 모호한 참조는 미해결로 표시한다. 관련 컬럼과 미사용 컬럼 대조군으로 시험 선정 결과를 다시 확인한다. [주문 스키마 회귀](27-SCHEMA-IMPACT-REGRESSION.md#독립-주문-서비스의-스키마-영향-검증)

## 후속 작업

일치율과 미해결 사례를 기준으로 지원할 SQL 형태의 범위를 정한다. [기능 우선 백로그](09-WBS-ROADMAP.md#기능-우선-백로그)

공개 배포는 보류한다. 공식 성능 시험과 남은 DB 지원 검증은 문서화된 선행조건을 충족한 뒤 재개한다. [배포와 지원 증거](30-RELEASE-SUPPORT-EVIDENCE.md) · [제품 G5 기준](32-PRODUCT-G5-ACCEPTANCE.md)
