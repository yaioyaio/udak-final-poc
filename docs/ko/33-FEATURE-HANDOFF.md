## 독립 주문 파일럿의 스키마 영향 검증

H2 도입 예제에서 SQL 실행 후 정규화가 불가능한 경우와 MyBatis 세션 캐시 적중을 구분해 검증했다. [관측 공백 예제](34-LEGACY-ADOPTION-PILOT.md#observe-관측-공백-진단)

## 범위와 인수 조건

NEXT-004 스키마 계약 후속을 진행한다. 독립 주문 파일럿에서 쿼리와 컬럼의 명시적 의존성을 기록하고, 지정 컬럼 변경 시 영향을 받는 주문 테스트가 선정되는지 검증한다. 관련 없는 컬럼 변경을 대조군으로 확인한다. [스키마 영향과 회귀](27-SCHEMA-IMPACT-REGRESSION.md)

## 후속 작업

파일럿 결과를 바탕으로 마이그레이션 이력 기반 원인 확인과 의존성 자동 추출을 평가한다. [기능 우선 백로그](09-WBS-ROADMAP.md#기능-우선-백로그)

공개 배포는 보류한다. 공식 성능 시험과 남은 DB 지원 검증은 문서화된 선행조건을 충족한 뒤 재개한다. [배포와 지원 증거](30-RELEASE-SUPPORT-EVIDENCE.md) · [제품 G5 기준](32-PRODUCT-G5-ACCEPTANCE.md)
