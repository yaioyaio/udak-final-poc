## 주문 파일럿의 정적 UPDATE 의존성 검증

지원하는 정적 감사 SQL 두 문장이 명시 매니페스트와 일치했다. 자동 추출만으로는 인벤토리 4개 중 1개의 참조를 완전히 해석했다. 검토한 참조와 추출한 감사 기록 의존성을 함께 사용해 주문 시험 선정 결과를 보존했다. [추출 검증 결과](27-SCHEMA-IMPACT-REGRESSION.md#정적-sql에서-컬럼-의존성-추출)

## 범위와 인수 조건

렌더링된 두 재고 UPDATE의 SET·WHERE 절에서 테이블과 컬럼 참조를 검증한다. 각 분기에 대해 명시적 기대 참조를 정하고 활성 재고 조건을 켰을 때 추가되는 컬럼을 확인한다. 동적 MyBatis 템플릿과 모호한 참조는 미해결로 남긴다. 재고 컬럼 변경과 미사용 컬럼 대조군으로 시험 선정도 검증한다. [주문 스키마 회귀](27-SCHEMA-IMPACT-REGRESSION.md#독립-주문-서비스의-스키마-영향-검증)

## 후속 작업

대조 결과를 바탕으로 추출기에 검증한 UPDATE 형태를 지원할지 결정한다. [기능 우선 백로그](09-WBS-ROADMAP.md#기능-우선-백로그)

공개 배포는 보류한다. 공식 성능 시험과 남은 DB 지원 검증은 문서화된 선행조건을 충족한 뒤 재개한다. [배포와 지원 증거](30-RELEASE-SUPPORT-EVIDENCE.md) · [제품 G5 기준](32-PRODUCT-G5-ACCEPTANCE.md)
