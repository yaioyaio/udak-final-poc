## 지문을 관측한 테스트 연결 검증 완료

v2 인벤토리는 각 SQL 지문을 실제로 관측한 테스트를 기록한다. H2 주문 파일럿에서 같은 Query ID의 재고 지문 두 개가 서로 다른 테스트와 연결됐다. 스키마 영향 CLI는 두 연결의 뒤바뀜을 모두 탐지했고 테스트를 0건 선정했다. [지문을 관측한 테스트 연결 검증](27-SCHEMA-IMPACT-REGRESSION.md#지문을-관측한-테스트-연결-검증)

## 검증 범위

보호 H2 주문 실행에서 수집 단언 89개, 선정 테스트 재실행 단언 27개, 스키마 영향 계약 34건, SQL 의존성 추출 계약 16건과 Core 스모크를 통과했다. 기존 인벤토리 실행기는 Java 계약 단언 94개, H2 어댑터 단언 14개, PR CLI 테스트 24건을 통과했다. 외부 DB 연동은 NOT RUN이다. [지문별 실제 관측 테스트 검증 증거](../../evidence/ORDER-OBSERVED-FINGERPRINT-TESTS-VALIDATION.json)

## 후속 작업

PR 변경 보고서에 지문별 관측 테스트 연결의 추가·삭제를 표시한다. 테스트 커버리지 변화와 SQL 형태 변경을 구분하고, 기존 v1 스냅샷을 함께 비교하는 경우도 검증한다.

공개 배포는 보류한다. 공식 성능 시험과 남은 DB 지원 검증은 문서화된 선행조건을 충족한 뒤 재개한다. [배포와 지원 증거](30-RELEASE-SUPPORT-EVIDENCE.md) · [제품 G5 기준](32-PRODUCT-G5-ACCEPTANCE.md)
