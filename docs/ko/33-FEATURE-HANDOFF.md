## 주문 재고 OFF·ON PR 재실행 검증 완료

같은 PR 보고서에서 등록된 재고 OFF·ON을 선정했다. 두 테스트는 관련 스키마 해시를 확인한 뒤 각 보호 진입점으로 새 H2에서 실행됐다. 미사용 컬럼을 변경한 대조 스키마의 해시는 두 진입점이 모두 거부했다. [주문 재고 OFF·ON 재실행 증거](25-SQL-INVENTORY-PR-REPORT.md#영향-테스트-해시를-주문-회귀-테스트에-연결)

## 검증 범위

보호 실행에서 H2 수집 단언 89개, OFF 재실행 단언 26개, ON 재실행 단언 27개, PR 대조 계약 12건, 스키마 영향 계약 34건, SQL 추출 계약 16건과 Core 스모크가 통과했다. 스키마 불일치 두 건은 모두 거부했다. 외부 DB 연동은 NOT RUN이다. [주문 재고 OFF·ON 재실행 증거](../../evidence/ORDER-STOCK-PR-REPLAY-VALIDATION.json)

## 후속 작업

PR 보고서와 스키마 영향 결과를 주문 파일럿의 로컬 CI 게이트에 연결한다. 등록된 테스트가 보호 진입점으로 실행되는지, 불완전·미등록·스키마 불일치 증거가 검토 항목으로 남는지 검증한다.

공개 배포는 보류한다. 공식 성능 시험과 남은 DB 지원 검증은 문서화된 선행조건을 충족한 뒤 재개한다. [배포와 지원 증거](30-RELEASE-SUPPORT-EVIDENCE.md) · [제품 G5 기준](32-PRODUCT-G5-ACCEPTANCE.md)
