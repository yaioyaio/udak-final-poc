## 주문 PR 회귀 테스트 대조 검증 완료

주문 파일럿은 영향 테스트 해시를 고정 회귀 진입점에 연결한다. H2 주문 PR 보고서에서 재고 ON이 보호 재실행으로 연결됐다. 재고 OFF 미등록 해시와 혼합·불완전 보고서는 검토 항목으로 남았다. [영향 테스트 해시를 주문 회귀 테스트에 연결](25-SQL-INVENTORY-PR-REPORT.md#영향-테스트-해시를-주문-회귀-테스트에-연결)

## 검증 범위

보호 실행에서 PR 대조 계약 11건, 스키마 영향 계약 34건, SQL 추출 계약 16건, H2 수집 단언 89개, 선정된 ON 재실행 단언 27개와 Core 스모크가 통과했다. 외부 DB 연동은 NOT RUN이다. [주문 PR 회귀 테스트 대조 증거](../../evidence/ORDER-PR-REGRESSION-MAPPING-VALIDATION.json)

## 후속 작업

주문 파일럿의 재고 조건 OFF 테스트를 독립 보호 재실행으로 검증하고 등록한다. 같은 PR 보고서에서 OFF·ON을 각각 선정하고 일치한 스키마에서 실행하는지 확인한다.

공개 배포는 보류한다. 공식 성능 시험과 남은 DB 지원 검증은 문서화된 선행조건을 충족한 뒤 재개한다. [배포와 지원 증거](30-RELEASE-SUPPORT-EVIDENCE.md) · [제품 G5 기준](32-PRODUCT-G5-ACCEPTANCE.md)
