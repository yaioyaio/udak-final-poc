## 승인된 레거시 프로젝트에서 NEXT-005 이어서 진행

NEXT-001~NEXT-004는 작업 범위의 검증을 통과했다. NEXT-005 레거시 적용 가이드와 내부 H2 리허설은 통과했고, 외부 시범 적용은 NOT RUN이다. [추적성](16-TRACEABILITY.md) · [도입 가이드와 결과](34-LEGACY-ADOPTION-PILOT.md)

## 범위와 인수 조건

승인된 레거시 애플리케이션과 테스트 환경 한 곳을 지정한다. 업무 흐름 한 곳을 Observe OFF와 ON으로 실행해 결과와 롤백이 같은지 확인한다. 유지보수 담당자가 합의한 대조군을 기준으로 유효 발견과 오탐을 검토한다. 검토한 건수, 구성 변경과 설정 시간을 업무 데이터 없이 기록한다. [시범 적용 절차](34-LEGACY-ADOPTION-PILOT.md#승인된-레거시-프로젝트에-적용)

## 후속 작업

승인 파일럿 증거를 바탕으로 진단, 설정 안내 또는 지원 범위 변경의 우선순위를 정한다. [기능 우선 백로그](09-WBS-ROADMAP.md#기능-우선-백로그)

공개 배포는 보류한다. 공식 성능 시험과 남은 DB 지원 검증은 문서화된 선행조건을 충족한 뒤 재개한다. [배포와 지원 증거](30-RELEASE-SUPPORT-EVIDENCE.md) · [제품 G5 기준](32-PRODUCT-G5-ACCEPTANCE.md)
